# Emotion Detection System

A microcontroller-based system that uses a sound sensor to detect variations in sound intensity and displays the corresponding detection result on a 16x2 LCD.

## Features

- Sound intensity detection
- Real-time sensor readings
- LCD display
- Arduino-based processing
- Simple and low-cost implementation

## Components Used

- Arduino UNO
- KY-038 Sound Sensor
- 16x2 LCD
- 10K Potentiometer
- Breadboard
- Jumper Wires
- USB Cable

## Software

- Arduino IDE
- Embedded C/C++

## Working

The KY-038 sound sensor detects changes in sound intensity. The Arduino reads the sensor value and categorizes the detected level as Calm, Normal, or Excited. The result is displayed on the LCD in real time.

## Applications

- Human-computer interaction
- Sound-based monitoring
- Embedded system demonstrations
- Basic emotion-related experiments
