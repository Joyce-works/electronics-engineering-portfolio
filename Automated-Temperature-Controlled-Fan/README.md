# Automated Temperature-Controlled Fan

A microcontroller-based system that automatically controls a fan according to the surrounding temperature.

## Features

- Automatic temperature monitoring
- Automatic fan control
- Temperature-based switching
- Reduced manual operation
- Simple and low-cost design

## Components Used

- Arduino UNO
- Temperature Sensor
- DC Fan
- Transistor/Motor Driver
- Resistors
- Breadboard
- Jumper Wires
- Power Supply

## Software

- Arduino IDE
- Embedded C/C++

## Working

The temperature sensor continuously measures the surrounding temperature. The Arduino processes the sensor reading and controls the fan according to a predefined temperature threshold. When the temperature rises above the threshold, the fan turns ON, and when the temperature falls below the threshold, the fan turns OFF.

## Applications

- Automatic cooling systems
- Electronic equipment cooling
- Smart home applications
- Temperature-based automation
